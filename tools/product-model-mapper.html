How It Works
  1. Upload your new SKU list (Material ID + Short Description required, Vendor Part # and Brand helpful).
  2. Upload your full or filtered content report export from the PIM.
  3. Call 1: Claude reads product descriptions from your new SKU list and all unique brand names from the content report, then identifies which catalog brands belong to the same family — handling abbreviations, sub-brands, and name variations automatically.
  4. You review the matched brands and row count before the main analysis runs.
  5. Call 2: Claude compares each new SKU against the filtered catalog and returns a structured recommendation for every SKU.
  6. Download an Excel file with color-coded recommendations ready for your modeling workflow.
